Where this model stops

The test set comes from the same synthetic distribution as training. Low error here does not establish accuracy on real hardware, other support conditions, new cross sections or loads outside this envelope. The largest observed errors matter even when the average looks excellent.

Training limits: L 200–1,000 mm; b 15–60 mm; h 10–60 mm; E 69–210 GPa; F 10–500 N. Additional filters: L/h ≥ 10, reference δ/L ≤ 2%, reference stress ≤ 200 MPa. The stress limit is a data filter, not a material strength limit.

A neural network is a learned equation.

Here is what that means for a mechanical engineer, using the model you can actually run.

Read the full guide ↗
01 / THE PROBLEM

How much does the beam bend?

Clamp one end of a rectangular beam and push down on the other. Length, width, height, stiffness and force determine its elastic response. Our network takes those five numbers and returns two predictions: tip deflection and maximum root bending stress.

δ = FL³ / (3EI)
σ = 6FL / (bh²)
I = bh³ / 12

The equations provide known answers for training. The network learns an approximation from examples; it does not call these equations to produce its prediction.

02 / THE NETWORK

Thousands of adjustable numbers.

5inputs→64neurons→64neurons→2outputs

Each neuron combines numbers from the previous layer: multiply by weights, add a bias, then apply a curved function called tanh. The curves let the network represent nonlinear relationships.

Training adjusts 4,674 weights and biases. The hidden neurons are mathematical features; none is guaranteed to represent a named physical quantity.

03 / LEARNING

Predict. Measure error. Adjust. Repeat.

We generate 10,000 valid beam cases. The network starts with random weights. It predicts 256 cases at a time, compares predictions with their known answers, and measures a loss.

Backpropagation calculates how each weight contributes to that loss. Adam uses these gradients to update the weights. An epoch is one pass through the training set.

Inputs are standardized using training data only. Outputs are learned in log space to handle responses spanning different magnitudes.

04 / CHECKING THE WORK

Keep the final exam separate.

The training set teaches. The validation set selects the saved checkpoint. The test set stays separate until that choice is finished. Mixing them would give an overly optimistic result.

A mean error of 0.57% does not mean every prediction is within 0.57%. Look at the 95th percentile and worst case. Neither gives a guaranteed error bound for a new design.

ANSYS checks a few separate beam models to test numerical consistency. Actual experiments would be another level of validation.

Why use AI if the equation already exists?

For this beam, use the equation: it is simpler, exact under its assumptions and cheap to evaluate. This project makes the surrogate-model workflow understandable and testable. The next application would replace these simple labels with expensive, carefully verified simulations of a more complex component.

The transferable skills are data generation, Python automation, neural-network training, validation, model deployment and knowing when an approximation is appropriate.
