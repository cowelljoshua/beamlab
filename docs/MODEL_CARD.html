BEAMLAB / PROJECT NOTES

BeamLab model card

Task: supervised regression of tip-deflection magnitude (mm) and maximum root bending-stress magnitude (MPa) for an end-loaded rectangular cantilever.

Architecture: dense 5–64–64–2, tanh hidden activations, linear transformed output. 4,674 parameters. Input standardization; natural-log target standardization; inverse transform with exp. Adam optimizer, batch size 256, 500-epoch cap, validation checkpoint selection. All source is included.

Data: 10,000 synthetic cases generated by rejection sampling. The five initial inputs are independent uniform random variables within the bounds in beamnet/physics.py; the filters introduce dependence in accepted cases. No personal data, experiments, confidential industrial data or ANSYS labels.

Split: 6,000/2,000/2,000, random permutation seed 2026. Data seed 42, initialization seed 7, batch-shuffle seed 19. Preprocessing uses training only. Selected epoch: 500. The training pipeline evaluated test predictions only after checkpoint selection. Verification may re-evaluate saved predictions for consistency; it does not select or modify weights.

Evaluation: reports/metrics.json has per-output MAE, RMSE, mean absolute percentage error, 95th-percentile absolute percentage error, maximum absolute percentage error and R². It also records high-stress and slenderness slices, the five worst cases by maximum output relative error, and environment details. reports/test_predictions.csv contains all test cases and predictions.

Baselines: a least-squares linear model on standardized physical inputs and standardized log targets. Closed-form equations have zero label error by construction. A log-input linear model can recover the power laws. The chosen linear baseline is an educational comparison, not evidence against all simple models. No measured runtime advantage is claimed.

Independent solver checks: ANSYS MAPDL 2026 R1, 18 solves, six geometries with 4/8/16 cubic BEAM188 elements, nu=0.3, linear static, all root DOFs fixed, tip force in negative global Y. Section dimensions are mapped so the bending inertia is b*h³/12. Stress is recovered from root element Mz and section modulus. Reaction equilibrium checked. Beam188 shear flexibility accounts for small differences from Euler–Bernoulli. No full 3D stress concentration is modeled.

Intended use: learning, recruiter demos, reproducible numerical experiments. Not established: real-hardware accuracy, uncertainty calibration, out-of-distribution reliability, structural safety or code compliance.

The 200 MPa stress filter is not a yield criterion. E alone does not define material strength. UI guards use the analytical reference to determine the training envelope; this is practical here because the reference is cheap. More expensive surrogate applications need their own appropriate guard method.

The browser evaluates fixed weights locally and does not store input histories or send designs to a backend. GitHub Pages serves static files only.

The illustration uses an assumed cantilever bending-curve shape scaled for visibility. The network predicts the tip magnitude, not a full displacement field; the beam outline is schematic.
